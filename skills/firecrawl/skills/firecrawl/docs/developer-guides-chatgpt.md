# Use Firecrawl MCP in ChatGPT

> Add Firecrawl to ChatGPT with the native plugin

Add Firecrawl to ChatGPT with the native Firecrawl plugin to search, scrape, crawl, interact with, and monitor the web from your chats. You do not need to create a custom MCP connector or paste a server URL.

## Add to ChatGPT

> [card] [Add to ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl)
>
> Open the Firecrawl plugin in ChatGPT and install it.

1. Open the [Firecrawl plugin in ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl), or open **Plugins** in ChatGPT and search for **Firecrawl**.
2. Select **Install**. When ChatGPT opens Firecrawl in your browser, sign in, choose a team, and approve access.
3. Start a new chat so ChatGPT loads the plugin, then ask it to use Firecrawl.

The same plugin works in Codex. See [ChatGPT & Codex](https://docs.firecrawl.dev/integrations/chatgpt-codex.md) for details and troubleshooting.

Do not put a Firecrawl API key in a server URL. To revoke access later, use [MCP settings](https://www.firecrawl.dev/app/settings?tab=mcp).

## Try

With Firecrawl enabled, try:

```text theme={null}
Search the web for the latest Firecrawl release notes and summarize the sources.
```

```text theme={null}
Scrape firecrawl.dev and tell me what it does
```
