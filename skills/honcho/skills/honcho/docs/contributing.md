# Contributing Guidelines

> How to contribute to Honcho, the open-source memory layer for AI agents: issues, pull requests, review and what gets accepted.

The full contributing guide lives in the repository, in
[`CONTRIBUTING.md`](https://github.com/plastic-labs/honcho/blob/main/CONTRIBUTING.md). It covers
how work gets approved, how Honcho is put together, how to file an issue, and what a mergeable
pull request looks like.

The short version:

* **Every pull request needs an approved issue.** Pick one labelled
  [`maintainer-approved`](https://github.com/plastic-labs/honcho/issues?q=is%3Aissue+is%3Aopen+label%3Amaintainer-approved),
  or open an issue and get it approved before you write code.
* **File issues only for what you hit in real use**, with the
  [issue templates](https://github.com/plastic-labs/honcho/issues/new/choose).
* **Come to [Discord](https://discord.gg/honcho)** if you feel strongly about a change. It's the
  fastest way to a decision.
