# Contributing Guidelines

> How to contribute to Honcho, the open-source memory layer for AI agents: issues, exceptions, and the AI usage policy.

Pull requests to Honcho are limited to maintainers. Open an
[issue](https://github.com/plastic-labs/honcho/issues/new/choose) instead. Think your work is an
exception? Make the case in [Discord](https://discord.gg/honcho).
