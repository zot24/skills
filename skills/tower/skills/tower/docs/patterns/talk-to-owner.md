# Talk to the owner

Status: **trial**. Owner will confirm the four-line shape.

## Report shape (every owner reply)

1. **Done or not**
2. **Useful or not** — one sentence
3. **What you do next** — one click, or “nothing”
4. Detail only if they ask

Do not lead with thread numbers, gate tables, or HAVE/STEAL.

## Cue when you launch someone

The owner cannot see herdr unless you say it. Every time you start or prompt a pane, say it **in the same reply**:

- **who** (role name)
- **what** (one line)
- **where** (space label)

Do not launch silently.

## Autolearn into the skill

When the tower finds something worth keeping (a steal, a failure we paid for, a better loop):

1. **Ask now.** One yes/no. Do not wait for the owner to remember.
2. If **yes**: write it into this skill (`docs/patterns/` + a README row). Same PR / same job.
3. If **no** or later: leave it in the knowledge base only.

Do not silently grow the skill. Do not dump a matrix and hope they pick.
