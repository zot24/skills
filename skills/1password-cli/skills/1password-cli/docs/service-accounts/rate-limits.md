# Service account rate limits


## <a href="#hourly-limits" class="anchor-link" aria-label="Navigate to header: Hourly limits"></a><span id="_R_b9deehkd74t9_" class="cursor-pointer">Hourly limits</span>


| Account type | Action | Limit | Period | Scope |
|----|----|----|----|----|
| <a href="https://support.1password.com/explore/business/" class="link" target="_blank" rel="noreferrer">1Password Business</a> | Read | 10,000 | 1 hour | Per service account token |
|  | Write | 1,000 | 1 hour | Per service account token |
| 1Password, <a href="https://support.1password.com/explore/families/" class="link" target="_blank" rel="noreferrer">1Password Families</a>, and <a href="https://support.1password.com/explore/team-admin/" class="link" target="_blank" rel="noreferrer">1Password Teams</a> | Read | 1,000 | 1 hour | Per service account token |
|  | Write | 100 | 1 hour | Per service account token |


- Wait for the 60-minute window to reset.
- <a href="https://support.1password.com/change-account-type/" class="link" target="_blank" rel="noreferrer">Change your 1Password account type.</a>
- <a href="https://support.1password.com/contact/" class="link" target="_blank" rel="noreferrer">Contact 1Password support.</a>
- <a href="/service-accounts/get-started/" class="link">Create a new service account.</a>  
  <span class="small">Hourly limits are scoped per service account token.</span>
