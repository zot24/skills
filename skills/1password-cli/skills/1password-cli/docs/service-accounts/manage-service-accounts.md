# Manage service accounts


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose the service account you want to manage.

### 


<a href="#create-a-usage-report-for-a-service-account" class="-ml-10 flex items-center opacity-0 border-0 group-hover:opacity-100 focus:opacity-100 focus:outline-0 group/link" aria-label="Navigate to header">​</a>


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose a service account.
4.  On the service account overview page, select **View Item Usage Report**.


### 


<a href="#change-a-service-account’s-name" class="-ml-10 flex items-center opacity-0 border-0 group-hover:opacity-100 focus:opacity-100 focus:outline-0 group/link" aria-label="Navigate to header">​</a>


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose a service account.
4.  Select **Edit Details**.
5.  Type a new name, then select **Save**.

### 


<a href="#rotate-token" class="-ml-10 flex items-center opacity-0 border-0 group-hover:opacity-100 focus:opacity-100 focus:outline-0 group/link" aria-label="Navigate to header">​</a>


1.  <a href="https://start.1password.com/sign-in/" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose a service account.
4.  Under the Token section, select **Rotate Token**.
5.  Select a value for **Expire existing token** to set when the token will expire.  
    <span class="small">For example, you can set the existing token to expire **now** (immediately), in **1 hour**, or in **3 days**.</span>
6.  Enter the service account name to confirm.
7.  Select **Rotate Token**.
8.  Select **Save in 1Password** to save the new token value in 1Password.


### 


<a href="#revoke-token" class="-ml-10 flex items-center opacity-0 border-0 group-hover:opacity-100 focus:opacity-100 focus:outline-0 group/link" aria-label="Navigate to header">​</a>


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose a service account.
4.  Under the Token section, select **Revoke Token**.
5.  Enter the service account name to confirm, then select **Revoke Token**.

<a href="#manage-who-can-create-service-accounts" class="-ml-10 flex items-center opacity-0 border-0 group-hover:opacity-100 focus:opacity-100 focus:outline-0 group/link" aria-label="Navigate to header">​</a>
