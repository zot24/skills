Service Accounts


# Manage service accounts


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose the service account you want to manage.

### <a href="#create-a-usage-report-for-a-service-account" class="anchor-link" aria-label="Navigate to header: Create a usage report for a service account"></a><span id="_R_99deehkd74t9_" class="cursor-pointer">Create a usage report for a service account</span>


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose a service account.
4.  On the service account overview page, select **View Item Usage Report**.


### <a href="#change-a-service-account’s-name" class="anchor-link" aria-label="Navigate to header: Change a service account’s name"></a><span id="_R_h9deehkd74t9_" class="cursor-pointer">Change a service account’s name</span>


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose a service account.
4.  Select **Edit Details**.
5.  Type a new name, then select **Save**.

### <a href="#rotate-token" class="anchor-link" aria-label="Navigate to header: Rotate a service account token"></a><span id="_R_n9deehkd74t9_" class="cursor-pointer">Rotate a service account token</span>


1.  <a href="https://start.1password.com/sign-in/" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose a service account.
4.  Under the Token section, select **Rotate Token**.
5.  Select a value for **Expire existing token** to set when the token will expire.  
    <span class="small">For example, you can set the existing token to expire **now** (immediately), in **1 hour**, or in **3 days**.</span>
6.  Enter the service account name to confirm.
7.  Select **Rotate Token**.
8.  Select **Save in 1Password** to save the new token value in 1Password.


### <a href="#revoke-token" class="anchor-link" aria-label="Navigate to header: Revoke a service account token"></a><span id="_R_139deehkd74t9_" class="cursor-pointer">Revoke a service account token</span>


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Service accounts** at the top of the page, then choose a service account.
4.  Under the Token section, select **Revoke Token**.
5.  Enter the service account name to confirm, then select **Revoke Token**.

## <a href="#manage-service-account-settings" class="anchor-link" aria-label="Navigate to header: Manage service account settings"></a><span id="_R_1b9deehkd74t9_" class="cursor-pointer">Manage service account settings</span>


### <a href="#manage-who-can-create-service-accounts" class="anchor-link" aria-label="Navigate to header: Manage who can create service accounts"></a><span id="_R_1f9deehkd74t9_" class="cursor-pointer">Manage who can create service accounts</span>


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Select <a href="https://start.1password.com/developer-tools" class="link" target="_blank" rel="noreferrer"><strong>Developer</strong></a> in the sidebar.
3.  Select **Permissions** at the top of the Developer page, then select **Service Account**.
4.  Select **Manage groups**, choose the groups you want to allow to create service accounts, then select **Update Groups**.

|--------------------|------------------|
| 1Password Teams    | `Allow Managing` |

### <a href="#manage-service-account-access-to-vaults" class="anchor-link" aria-label="Navigate to header: Manage service account access to vaults"></a><span id="_R_259deehkd74t9_" class="cursor-pointer">Manage service account access to vaults</span>


1.  <a href="https://start.1password.com/signin" class="link" target="_blank" rel="noreferrer">Sign in</a> to your account on 1Password.com.
2.  Choose the vault you want to change service account access to.
3.  Select **Manage**.
4.  Under Service Account Access, select the toggle to turn access on or off.
